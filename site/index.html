How to Add this Repository

1

Copy Repository URL

Copy the following link to your clipboard:

https://raw.githubusercontent.com/03DxD12/tachiyomi-extensions/repo/index.min.json
2

Open Extension Repositories in App

In Tachiyomi or Mihon, navigate to:

More → Settings → Browse → Extension repos

3

Add and Refresh

Tap Add repository, paste the copied URL, and tap Add.

Go to Browse → Extensions and pull down to refresh!
